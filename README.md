# 🎯 Number Guessing Game (Java)

A simple console-based number guessing game written in Java. The program generates a random number within a certain range, and the player has to guess the number with hints provided after each guess.

---

## 📌 Features

- Random number generation
- Input handling via console
- Feedback after each guess ("Too high", "Too low")
- Counts the number of attempts
- Simple and beginner-friendly code

---

## 🚀 How to Run

1. Clone the repository or download the source code.

2. Open a terminal or command prompt, navigate to the project directory, and compile the code:

   ```bash
   javac NumberGuessingGame.java
